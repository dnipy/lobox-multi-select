# Lobox Multi-Select Component

A simple reusable multi-select dropdown built for the Lobox Front-end Developer assignment.

## Assignment Requirements

- Multi drop-down select
- Add new items by typing and pressing Enter
- Close dropdown when clicking outside
- Use ReactJS
- Use TypeScript
- Use SCSS
- Match the provided design as much as possible
